
  # ROC Platform Frontend

  ROC平台（Robot Operation Control Platform）前端项目 - 机器人运营控制平台

  这是一个从 Figma 设计导出的 React + TypeScript 前端项目。原始设计文件：https://www.figma.com/design/XboBjsRliaN0X7YrnRoMYz/Login-and-Registration-Interface

  ## 技术栈

  - React 18 + TypeScript
  - Vite 6
  - React Router
  - Tailwind CSS
  - Radix UI 组件库

  ## 快速开始

  ### 安装依赖

  ```bash
  npm install
  ```

  ### 启动开发服务器

  ```bash
  npm run dev
  ```

  开发服务器将在 http://localhost:3000 启动

  ### 构建生产版本

  ```bash
  npm run build
  ```

  ## 项目结构

  ```
  roc-frontend/
  ├── src/              # 源代码目录
  │   ├── components/   # React 组件
  │   ├── styles/       # 样式文件
  │   └── main.tsx      # 应用入口
  ├── index.html        # HTML 入口文件
  ├── vite.config.ts    # Vite 配置
  └── package.json      # 项目配置
  ```
