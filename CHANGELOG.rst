=========
变更日志
=========

本文档记录项目的所有重要变更。

格式基于 Keep a Changelog <https://keepachangelog.com/zh-CN/1.0.0/>_，
并且本项目遵循 语义化版本 <https://semver.org/lang/zh-CN/>_。

==========
[0.2.1] - 2026-09-24
==========

新增
----
- 超级管理员邀请码列表增加服务端分页、状态筛选、总数和稳定排序，避免历史邀请码持续拉长账户管理页面或受原先最近 100 条限制。

变更
----
- 地图 PNG/JPEG 上传上限由 10 MiB 调整为 30 MiB；中文显示名与原始文件名在界面保留，multipart 使用安全英文传输名，服务端仍以随机英文键保存并按文件签名校验。

==========
[0.2.1-rc1] - 2026-09-23
==========

新增
----
- 增加 Python 虚拟车辆和 systemd 多实例模板，用于在服务器模拟 Device token WebSocket 心跳、遥测、断线重连及地图/路网制品交付。
- 车辆列表增加地图绑定选择器，支持已有车辆绑定、切换或解除项目地图；新增车辆时可直接选择地图并默认选中项目默认地图。

修复
----
- 修复前端虽然展示“未绑定地图”，却没有提供绑定入口，导致车辆无法进入地图监控视图的问题。
- 修复包含路网版本或地图制品的项目删除时返回 500：无交付引用时事务清理关联元数据并在提交后删除制品文件；有部署历史或车辆交付指针时稳定返回 HTTP 409。

安全
----
- 虚拟车辆从独立权限文件读取 Device token，持久 sequence 与任务事件幂等标识；下载制品需通过字节数、MIME 和 SHA-256 校验并原子落盘后才回报已送达。

==========
[0.2.0-rc.1] - 2026-09-23
==========

新增
----
- 增加构建机 release bundle 脚本，将 PostgreSQL、后端和前端的已构建版本化 Docker 镜像连同 SHA-256、manifest 与运行配置统一导出。
- 增加运行主机专用 Compose 和部署脚本，只允许校验、``docker load`` 与 ``--no-build --pull never`` 启动，不依赖源码或编译工具链。
- 增加一次性注册邀请码：超级管理员后台随机生成 5 位数字与大写字母组合，可查看使用状态并撤销未使用邀请码。
- 注册接口和页面要求邀请码；账户创建与邀请码消费在同一数据库事务中完成，并新增迁移 ``009_registration_invites.sql``。

变更
----
- 明确部署边界：所有编译与自动化测试在独立构建机执行，资源受限的主服务器只保存运行配置、持久卷并运行已交付镜像。

安全
----
- release 部署默认要求明确配置且复用现有 PostgreSQL/地图数据卷，卷名错误、CPU 架构不匹配、镜像校验失败或旧 Compose 容器冲突时拒绝启动，避免静默启用空数据库或错误制品目录。
- 同一邀请码只允许成功注册一个普通账户；已使用或已撤销的邀请码统一拒绝，邀请码生成使用系统密码学随机源并排除易混淆字符。

[0.1.0] - 2026-09-23
==========

新增
----
- C++ Drogon 后端、PostgreSQL 数据模型、REST API 与 WebSocket 状态通道。
- ``super_admin`` / ``regular`` 双角色认证和平台级账户管理边界。
- 项目、地图、车辆的归属校验、默认地图事务及跨项目绑定约束。
- 地图坐标元数据、路网 JSONB、受保护的地图图片读取和车辆遥测版本号。
- 每车独立 Device token 的签发、轮换、撤销和摘要存储。
- JSON Device Protocol v1、独立 ``/ws/device``、单车凭据握手、心跳、遥测与持久 sequence 幂等。
- WebSocket 首帧 JWT 认证、项目订阅、权限复核、心跳、重连和 REST 兜底。
- 持久下发批次、逐车任务、租约、幂等事件流水，以及在线通知与重连补发。
- 路网不可变版本和地图制品元数据模型，含大小、内容类型及 SHA-256。
- 路网编辑器：节点新增/拖动/删除、拓扑连边、属性编辑、撤销重做、草稿校验、脏状态提示与不可变版本历史。
- 路网版本列表、单版本读取和创建接口；后端执行字段白名单、坐标模式、引用、重复边、速度、体积校验并计算规范 JSON SHA-256。
- 路网版本一键下发界面：按当前地图和 Device token 资格选择车辆、二次确认、逐车进度、取消、按原版本重试与刷新恢复。
- 地图原图不可变制品：上传时自动生成 v1，旧地图可幂等固化；记录 MIME、尺寸、字节数、SHA-256 和独立存储键。
- 地图一键下发界面：按项目车辆和 Device token 资格选择目标，复用持久任务、逐车进度、取消、重试与刷新恢复。
- Device token 鉴权的任务接受、manifest、制品下载与状态回报接口。
- 浅色公开首页、登录/注册页和统一的登录后运营工作台导航。
- 项目地图、车辆列表、地图监控、个人中心和平台管理页面。
- 统一 SVG 坐标空间、矩形视口适配、锚点缩放和平移交互。
- Docker Compose、分离部署配置样例、健康检查和数据库迁移脚本。
- C++17 JSON envelope、身份隔离、字段校验和确认消息测试。
- OpenAPI 3.1 REST 合同，以及 Device Protocol v1、road-network v1 与 deployment-task v1 的机器可读 JSON Schema。
- API 合同测试、Playwright 路网画布/键盘测试与部署后 HTTP/API/数据库/WebSocket 验收脚本。

变更
----
- 地图制品和路网版本的容量展示统一为 KB，固定保留一位小数。
- 公开注册仅创建普通用户；全新数据库不再预置固定管理员账号或口令。
- 超级管理员可查看全平台账户及带所有者标识的项目、车辆；普通用户只能访问自己的资源。
- 地图上传由 JSON Base64 迁移为 ``multipart/form-data`` 的原始 PNG/JPEG 文件，最大 10 MiB；图片不再通过匿名静态路径公开。
- 车辆上报由 HTTP 协议桥改为 Device token 鉴权的 WebSocket JSON 常连接；车辆身份完全从凭据映射。
- 前端 API 默认使用同源路径，开发代理和生产构建地址通过环境变量配置。
- 前端 Nginx 在启动时读取 ``FRONTEND_BACKEND_UPSTREAM``，后端地图目录通过 ``BACKEND_MAP_VOLUME`` 持久化；部署脚本兼容 Compose v1/v2 并等待服务健康。
- 文档指南同步 JSON Device Protocol v1、持久设备任务、设备/浏览器双 WebSocket 通道、sequence 与 Demo 安全边界。
- 车辆 REST/浏览器实时快照增加 Device token 启用状态和已送达资源版本指针，供下发资格预检与状态展示。
- 设备制品下载明确为完整下载；不支持 Range，携带 Range 返回 HTTP 416。

修复
----
- 修复非法 UUID 导致 PostgreSQL 类型转换错误泄漏为 HTTP 500 的问题。
- 修复跨用户项目、地图、车辆、图片及管理员接口的越权访问。
- 修复地图删除、默认地图和车辆绑定时的跨项目或引用冲突。
- 修复矩形地图、缩放锚点、视口尺寸变化和旧遥测快照覆盖新状态的问题。
- 修复窄屏文档、认证页面和平台管理页面的横向溢出与布局问题。
- 修复重复设备消息可能重复写入状态的问题，最后 sequence 与遥测快照原子提交。
- 修复 libpqxx v6、Drogon v1、容器健康检查和 Nginx 动态解析兼容问题。
- 修复任务状态 SQL 复用参数在 PostgreSQL 中推断为 text/varchar 不一致的问题。
- 修复地图制品引入后删除地图可能触发外键错误的问题；无历史引用时事务清理版本和文件，有交付历史时明确返回冲突。
- 修复 Button 与 Dialog 遮罩组件未转发 ref 导致焦点管理或地图下发对话框产生 React 控制台警告的问题。
- 修复数据库健康检查向客户端暴露内部连接错误细节的问题。
- 修复地图卡片操作菜单被卡片边界裁剪的问题，并补齐键盘焦点与 Esc 关闭行为。

安全
----
- 账户 JWT 与设备凭据分离；设备明文凭据只在签发时返回一次。
- WebSocket 在认证前不接收业务广播，并对项目订阅执行授权检查。
- 上传地图只经 Bearer 鉴权接口返回，关闭旧 ``/static`` 匿名回退。
- 数据库初始化不包含固定密码、密码哈希或可直接登录的默认账户。
- 数据库容器和部署脚本不再提供可运行的默认密码；缺少 ``DB_PASSWORD`` 时拒绝启动。
- 每辆车只接受独立 Device token；移除部署级共享凭据和消息正文车辆身份；轮换或撤销会使旧会话立即失效。
- PostgreSQL 连接支持 ``disable``、``require``、``verify-ca`` 与 ``verify-full``；CA 和可选客户端证书通过只读目录挂载，配置缺失或不一致时拒绝启动。

移除
----
- 移除 ROS 协议入口、ROC 二进制、旧 ``status/command/pending`` HTTP 接口、内存指令队列、前端 mock 业务数据和无持久化能力的通知设置。
- 移除拖拽拼图验证、占位密码找回、占位政策链接和固定默认管理员。
